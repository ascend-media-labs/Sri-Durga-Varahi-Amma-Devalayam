# Sri Varahi Amma Temple

Devotional web application for Sri Varahi Amma Temple.

## Development

Prerequisites: Node.js (v18+) and npm.

### Installation

```sh
npm install
```

### Run Locally

```sh
npm run dev
```

The local development server will start at [http://localhost:8080/](http://localhost:8080/).

### Production Build

```sh
npm run build
npm run preview
```
